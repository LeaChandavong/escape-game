# Jack-O-mansion

Projet conçu en équipe avec : Lea, Naomi

## Le public cible

- Pour qui : 7+ familial
- Ce qui est important pour eux : Avoir un peu peur, s'amuser, se sentir intelligent. Avoir des consignes claires et une bonne sécuriter.

## La conception

- L'intrigue : Les personnages sont enfermer dans le manoir de Jack-o-lantern et ils doivent s'échapper par la porte de derrière avant qu'il revient. Mais ils doivent faire attention au majordome du manoir. Le majordome est aveugle donc il faut rester silencieux quand il arrive.
- Le nombre d'énigmes : 10
- Le type d'énigmes : puzzles, assemblages, hiérarchie, code couleur logique, calcul simple.
- Les besoins matériels : Deux chambres, des portrait épeurant, des lanterns sur les murs, un tapis, un faux corbeau, des citrouilles, un sofa, des chandelles, un coffre verrouillé, un faux foyer, des chaises, une table a manger, des assiettes, des verres, des décoration d'halloween
- Les besoins technologiques : Des projecteurs, des speakers, un compte a reboure.
- Les besoins humains : technicien en sons, technicien en éclairage, un acteur.
